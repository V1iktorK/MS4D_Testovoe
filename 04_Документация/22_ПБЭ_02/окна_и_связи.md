|---|---|
| **Режим работы** | Задание производительности вытяжки, % (`ЗадVВытяжки`); Задание температуры вытяжки, °C (`ЗадТВытяжки`) |
| **Выбор основного вентилятора** | Выбор основного вентилятора — **селектор** `ВыборОсновногоВент` (значения: Вентилятор 1 / Вентилятор 2 / Автоматическая ротация) |
| **Переключение и ротация** | Период переключения вентиляторов, ч (`ПериодПереключенияВент`); Ротация (`РотацияВключена`); Выдержка переключения, с (`ВыдержкаПереключения`); [кнопка] Ручное переключение |
| **Обслуживание** | Порог наработки вентилятора 1, ч (`МчВент1Порог`); Порог наработки вентилятора 2, ч (`МчВент2Порог`); [кнопка] Сброс моточасов; [индикатор] Текущие моточасы В1, В2 |
| **Воздушные заслонки** | Время хода заслонки, с (`ВрХодаЗаслонки`) |
| **Тревоги** | Задержка тревоги, с (`ЗадержкаТревоги`) |

### 4.2. Обязательные свойства полей ввода (рис. А.5)

`Минимум`, `Максимум`, `Шаг инкремента`, `Текущее значение`, **«Входящие связи» и «Исходящие связи» обе заполнены**, `Использовать вход…` включено.

> **Селектор `ВыборОсновногоВент`**: список значений задаётся строкой с разделителем `~` (рис. А.4): `Вентилятор 1~Вентилятор 2~Автоматическая ротация`.

### 4.3. Группы, которых НЕТ
«Рециркуляция», «Роторный рекуператор», «Пароувлажнитель», «Водяной нагреватель» — приточные узлы, не переносятся (ТЗ п. 3.1).

## 8. Программа ST

### 8.1. Что делает и чего не делает

| Делает | Не делает |
|---|---|
| Ограничивает уставки (`LIMIT`) | Не разбирает битовые маски (их нет) |
| Считает **моточасы** двух вентиляторов | Не управляет шкафом как единым устройством |
| Считает **пуски** по фронту обратной связи | Не содержит планировщика (его нет) |
| Выбирает **основной вентилятор** по `ВыборОсновногоВент` | Не пишет расписание в контроллер |
| Выполняет **автоматическую ротацию** по наработке | |
| Выполняет **ручное переключение** | |
| Формирует тексты состояния и ротации | |
| Формирует команды и учитывает обратную связь | |
| Вводит резерв при аварии основного | |
| Формирует аварии/предупреждения, коды `-1` | |

### 8.2. Структура программы

| Раздел | Содержание |
|---|---|
| — | Снимки обратной связи `r1`, `r2` в начале цикла |
| 1 | Ограничение вводимых уставок |
| 2 | Второй вентилятор отключён настройкой; зеркальный признак; взаимоисключение команд |
| 3 | **Моточасы** вентиляторов, **счётчики пусков**, диагностика, сервисный сброс |
| 4 | **Выбор основного вентилятора, переключение и ротация** |
| 5 | **Команды и обратная связь**, ввод резерва при аварии основного |
| 6 | Состояние заслонки |
| 7 | Расход вытяжки |
| 8 | Аварии и предупреждения, коды `-1` |
| 9 | Состояние системы по приоритету |

### 8.3. Ключевые технические решения

| Решение | Почему так |
|---|---|
| **Снимки `r1`, `r2` в начале цикла** | Роли вентиляторов меняются в разделе 4, после чего раздел 5 переписывает команды. Если бы моточасы считались по свежему значению, наработка могла бы начисляться не тому вентилятору |
| **Дробная и целая части наработки раздельно** | Шаг 1 с = 1/3600 ч. Целочисленное накопление «съедало» бы каждое приращение. Дробная часть в REAL, при достижении 1.0 переносится в INT |
| **`ШагПрограммыСек` — параметр настройки** | Фактическую длительность цикла в проверенном перечне функций получить нечем. Вынесено в параметр, чтобы уточнялось без правки кода (допущение `D-21`) |
| **`НастрСчитатьМоточасы`** | Если ДИГАМ передаст моточасы от контроллера — параметр переводится в приём из канала, блок наработки отключается флагом |
| **Пуски считаются по фронту `РаботаВентN`** | Предыдущее состояние хранится в `РаботаВентNПред`. Библиотечный `R_TRIG` не используется, чтобы не зависеть от формы его вызова в этой сборке |
| **Переназначение ролей одной формулой** | `ОсновнойВент := 3 - ОсновнойВент` — переключение 1↔2 без ветвлений. Работает, потому что роли только две |
| **`ПереключениеВыполнено` сбрасывается в начале раздела 4** | Признак — событие одного цикла, а не состояние |
| **При жёстком выборе (`=1` или `=2`) ротация блокируется** | `ПереключениеРазрешенo := FALSE` — оператор задал основного вручную |
| **Авария основного вводит резервный** | В разделе 5: при `АвВент1` включается команда пуска В2 и останов В1. Это **резервирование уровня экземпляра**, а не логика резерва шкафа |
| **`ЕстьАвария := (v>0) AND NOT ДиагНетСвязи`** | Потеря связи не маскируется под аварию |
| **Аварии отключённых узлов не учитываются** | `IF НастрЕстьВторойВент AND АвВент2 THEN v := 1` — при выключенном вентиляторе 2 его авария игнорируется |

### 8.4. Форма кавычек
Использованы **одинарные** кавычки (24 литерала). Если компилятор требует двойные — заменить во всём файле и сообщить мне.
