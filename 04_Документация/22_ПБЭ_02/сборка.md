# ПБЭ № 2. Инструкция по сборке в MasterSCADA 4D 1.3.10.34633

**Кто выполняет:** пользователь. Материал — этот документ плюс `параметры.md`, `окна_и_связи.md`, `st/Программа_ST_1.st`.
**Что получится:** библиотечный элемент парной вытяжной системы с 12 окнами, моточасами и ротацией.
**Оценка времени:** ≈ 18 ч.

> **Главное отличие ПБЭ № 2 от ПБЭ № 3:** здесь есть **два вентилятора** (основной и резервный), **моточасы** и **ротация**. Планировщика и кнопки «РАСПИСАНИЕ» по-прежнему **нет**.

3. Открыть `22_ПБЭ_02/параметры.md` и `22_ПБЭ_02/окна_и_связи.md`.

### 2.4. Выбор вентилятора и ротация (12 шт.)
`ВыборОсновногоВент`, `ОсновнойВент`, `РезервныйВент`, `ПериодПереключенияВент`, `НаработкаОсновного`, `НаработкаРезервного`, `МчВент1Порог`, `МчВент2Порог` (INT); `РотацияВключена`, `ПереключениеВыполнено`, `ПереключениеРазрешено` (BOOL); `ВыдержкаПереключения` (TIME); `ВрПоследнегоПереключения` (**DT, направление Вх** — принимается из канала, см. ниже).

> **Внимание.** **Уточнение по среде.** Функции получения текущего времени в MasterSCADA 4D 1.3.10.34633 **нет** (`GET_LOCAL_TIME` отсутствует — проверено пользователем). Поэтому `ВрПоследнегоПереключения` объявлен **входным** (`Вх`): ДИГАМ подключает его к системному тегу времени. **Логика ротации и АВР от этого параметра не зависит** — она работает по наработке (`МчВент1`, `МчВент2`) и уставке `ПериодПереключенияВент`. Параметр служит для протоколирования времени переключения.

> `ВыборОсновногоВент`: `Минимум = 1`, `Максимум = 3`. Список значений — `Вентилятор 1~Вентилятор 2~Автоматическая ротация`.
> `ПериодПереключенияВент`: значение по умолчанию **50** (рис. 1.3), `Минимум = 1`, `Максимум = 10000`.

## Шаг 4. Программа ST (3 ч — самый ответственный шаг)

1. `Ресурсы → Программы` → создать `Программа_ST_1`, язык ST.

### 4.1. Что проверить в коде после вставки

| Что | Где | Ожидание |
|---|---|---|
| Снимки `r1`, `r2` **до** всех расчётов | начало программы | Есть |
| Дробная и целая части наработки | раздел 3 | Есть перенос при `>= 1.0` |
| `НастрСчитатьМоточасы` учитывается | раздел 3 | Есть в обоих блоках |
| `РаботаВентNПред` обновляется | раздел 3 | Есть |
| `ПереключениеВыполнено := FALSE` **до** проверки ротации | раздел 4 | Есть |
| `ОсновнойВент := 3 - ОсновнойВент` | раздел 4 | Есть (ручная и авто ротация) |
| `НастрЕстьВторойВент` гасит команды В2 | раздел 2 и 5 | Есть |
| `GetBit` отсутствует | везде | Не должно быть |

### 4.2. Если ошибки компиляции

| Ошибка | Причина | Решение |
|---|---|---|
| «Неизвестный идентификатор `ШагПрограммыСек`» | параметр не создан | создать (шаг 2.6) |
| «Неизвестный идентификатор `РаботаВент1Пред`» | параметр не создан | создать (шаг 2.5) |
| Ошибка на `TIME_TO_INT` | иное имя функции | функция подтверждена как верная; сообщить мне |
| Ошибка на `LIMIT` | иные имена аргументов | имена `MN`/`IN`/`MX` **подтверждены как верные** — если ошибка осталась, сообщить мне |
| Ошибка на строковых литералах | форма проверена: требуются двойные кавычки | в файле уже двойные кавычки; заменить программу из файла |
| «Тип несовместим» на `ВрПоследнегоПереключения` | параметр объявлен не как DT | переделать тип на DT |

## Шаг 5. Окно 2.12 «Мнемосхема установки» (3 ч)

### 5.1. Мнемосхема (два вентилятора)

## Шаг 12. Настройка `ШагПрограммыСек` по факту (30 мин)

> Если фактическая периодичность неизвестна и измерить не удаётся — оставить `1.0` и сообщить мне: подберём другой способ (например, накопление по метке времени).

## Частые ошибки и что делать

| Симптом | Причина | Решение |
|---|---|---|
| **Мнемосхема получила номер 2.1** | «причесали» нумерацию | вернуть **2.12** по Перечню (?) |
| Моточасы не растут | `НастрСчитатьМоточасы = FALSE` или `РаботаВентN` не приходит | проверить настройку и обратную связь |
| Моточасы растут слишком быстро | `ШагПрограммыСек` больше фактического цикла | измерить и исправить (шаг 12) |
| Моточасы растут на единицу каждый цикл при шаге 1 с | пользовались шагом 12 без возврата значения | вернуть `ШагПрограммыСек = 1.0` |
| Наработка начисляется не тому вентилятору | убрали снимки `r1`, `r2` из начала программы | восстановить строки в начале |
| Ротация переключает роли каждый цикл | `ПереключениеВыполнено` не сбрасывается в начале раздела 4 | проверить порядок строк |
| Ротация не срабатывает | `РотацияВключена = FALSE` или `ВыборОсновногоВент ≠ 3` | выставить оба |
| `ОсновнойВент` стал 0 или 3 | испортили формулу `3 - ОсновнойВент` | восстановить |
| Счётчик пусков считает циклы, а не пуски | убрали `РаботаВентNПред` | восстановить |
| Оба вентилятора «основные» | метки `Основной`/`Резервный` связаны с одним параметром | каждая метка — свой конвертер по `ОсновнойВент` |
| Таблица состояния «поехала» | 2.1 и 2.2 не согласованы | сверить по T2-51 |
| Появилась панель «Планировщик» | скопировали рис. 1.1 целиком | удалить |
| `LIMIT`/кавычки — ошибка компиляции | особенности сборки | сообщить мне |
