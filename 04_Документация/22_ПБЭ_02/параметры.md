# ПБЭ № 2. Таблица параметров

Направление: **Вх** — приём из канала (подключает ДИГАМ); **Вых** — значение, формируемое ПБЭ; **Настр** — настройка экземпляра; **Выч** — вычисляемое внутри ПБЭ.

## 4. Выбор основного вентилятора и ротация (11 шт.)

| № | Параметр | Тип | Напр. | Диапазон / значения | Описание |
|---|---|---|---|---|---|
| 40 | `ВыборОсновногоВент` | INT | Вых | **1** Вентилятор 1, **2** Вентилятор 2, **3** Автоматическая ротация | Выбор основного вентилятора. Задаётся оператором в окне 2.7 |
| 41 | `ОсновнойВент` | INT | Выч | 1, 2 | Кто сейчас основной (вычисляется программой) |
| 42 | `РезервныйВент` | INT | Выч | 1, 2 | Кто сейчас резервный |
| 43 | `РотацияВключена` | BOOL | Вых | FALSE/TRUE | Разрешение автоматической ротации |
| 44 | `ПериодПереключенияВент` | INT | Вых | 1…10000 ч | Период переключения вентиляторов, ч. По умолчанию **50** (рис. 1.3) |
| 45 | `ПереключениеВыполнено` | BOOL | Выч | FALSE/TRUE | Признак: ротация выполнена |
| 46 | `ВыдержкаПереключения` | TIME | Вых | 0…3600 с | Выдержка между переключениями |
| 47 | `ВрПоследнегоПереключения` | DT | **Вх** | — | Время последнего переключения. **Принимается из канала**: штатной функции получения текущего времени в среде нет (см. примечание ниже) |
| 48 | `НаработкаОсновного` | INT | Выч | 0…1000000 ч | Наработка текущего основного вентилятора |
| 49 | `НаработкаРезервного` | INT | Выч | 0…1000000 ч | Наработка текущего резервного |
| 50 | `МчВент1Порог` | INT | Вых | 1…1000000 ч | Порог наработки вентилятора 1 для сигнала «требуется обслуживание» |
| 51 | `МчВент2Порог` | INT | Вых | 1…1000000 ч | То же для вентилятора 2 |

> **Внимание.** **Уточнение по среде.** Штатной функции получения текущего времени в MasterSCADA 4D 1.3.10.34633 **нет** (функция `GET_LOCAL_TIME` отсутствует). Поэтому параметр `ВрПоследнегоПереключения` объявлен **входным** (`Вх`): его значение **принимается из канала**. ДИГАМ подключает его к системному тегу времени в рабочем проекте. Программа ротации и АВР **от этого параметра не зависит** — она работает по наработке (`МчВент1`, `МчВент2`) и по уставке `ПериодПереключенияВент`. Параметр служит **для протоколирования** времени переключения.

| № | Параметр | Тип | Напр. | Описание |

| 62 | `МчВент1Дроб` | REAL | Выч | Дробная часть наработки вентилятора 1, ч (для точности накопления) |
| 63 | `МчВент2Дроб` | REAL | Выч | Дробная часть наработки вентилятора 2, ч |
| 64 | `КолПереключенийВент1` | DINT | Выч | Число пусков вентилятора 1 |
| 65 | `КолПереключенийВент2` | DINT | Выч | Число пусков вентилятора 2 |
| 66 | `МчВент1Обслуживание` | BOOL | Выч | Наработка вентилятора 1 превысила порог |
| 67 | `МчВент2Обслуживание` | BOOL | Выч | Наработка вентилятора 2 превысила порог |
| 68 | `РаботаВент1Пред` | BOOL | Выч | Предыдущее состояние обратной связи В1 — для подсчёта пусков по фронту |
| 69 | `РаботаВент2Пред` | BOOL | Выч | Предыдущее состояние обратной связи В2 — для подсчёта пусков по фронту |
| 70 | `ШагПрограммыСек` | REAL | Настр | Длительность цикла программы, с. По умолчанию **1.0**. См. примечание ниже |

> **Примечание к `ШагПрограммыСек` (допущение `D-21`).** Моточасы накапливаются умножением на длительность цикла. Штатного способа получить фактическое время предыдущего вызова программы в проверенном перечне функций MasterSCADA 4D нет, поэтому длительность цикла вынесена в **параметр настройки**. Значение `1.0` соответствует шагу 1 секунда.
>
> **Что сделать при сборке:** измерить фактическую периодичность вызова программы (по счётчику циклов за известный интервал) и записать полученное значение в `ШагПрограммыСек`. Точность моточасов прямо пропорциональна точности этого параметра. Замена значения не требует правки ST-кода.
>
> **Альтернатива.** Если ДИГАМ передаст моточасы готовыми от контроллера, параметры `МчВент1`/`МчВент2` переводятся в режим «приём из канала», а блок 3 программы отключается флагом `НастрСчитатьМоточасы = FALSE` (см. §2).

## 15. Резервные параметры (объявлены, но ПБЭ не использует)

Параметры ниже присутствуют в перечне сигналов оборудования, поэтому объявлены в таблице,
но **не участвуют** ни в программе, ни в привязках окон, трендов и сообщений.
Они создаются «на будущее» либо не создаются вовсе — решение принимает сборщик.
Такие параметры отмечены как резервные — это не ошибка: ошибкой считается только
вычисляемый параметр, который программа не заполняет.

| Параметр | Почему не используется |
|---|---|
| `ЗапускУспешен` | Признак оборудования из перечня. В логике ПБЭ не участвует — резерв. |
| `ЛетнийРежим` | Признак оборудования из перечня. В логике ПБЭ не участвует — резерв. |
