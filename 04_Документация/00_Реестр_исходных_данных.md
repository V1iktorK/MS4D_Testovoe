### Рисунок А.2 — фрагмент программы обработки аварий (ST)
Восстановленный текст (левая и правая части рисунка сведены; читается дословно):

```st
VAR
    i : INT;
    n : INT;
    k : INT;
    s : STRING;
    v : INT;
END_VAR

v := ВариантАварий.Value;
IF v = 0 THEN v := 1; END_IF;

IF v = 4 THEN
    (* П7. Слово критических аварий одно, раскладка снята из копии AS06:
       0 пожар, 1 заслонка вытяжки, 2 заслонка притока,
       3 заслонка рециркуляции вытяжки, 4 заслонка рециркуляции притока,
       5 вентилятор притока, 6 вентилятор вытяжки,
       7 низкая температура помещения, 8 обрыв датчика температуры помещения.
       Аварии вентиляторов приходят и отдельными точками, их пишет канал. *)
    Пожар.Value                  := GetBit(IN := АварияКрит1.Value, N := 0);
    АвЗаслВыт.Value              := GetBit(IN := АварияКрит1.Value, N := 1);
    АвЗаслПрит.Value             := GetBit(IN := АварияКрит1.Value, N := 2);
    АвПолохЗаслРецВыт.Value      := GetBit(IN := АварияКрит1.Value, N := 3);
    АвПолохЗаслРецПрит.Value     := GetBit(IN := АварияКрит1.Value, N := 4);
    ОбрывТПомещения.Value        := GetBit(IN := АварияКрит1.Value, N := 8);

    n := 0;
    k := -1;
    FOR i := 0 TO 8 DO
        IF GetBit(IN := АварияКрит1.Value, N := i) THEN
            n := n + 1;
            IF k < 0 THEN k := i; END_IF;
        END_IF;
    END_FOR;

    ЕстьАвария.Value   := n > 0;
    ЕстьПредупр.Value  := Предупреждение.Value;
    КодПредупр.Value   := -1;
    IF n = 0 THEN
        КодАварии.Value := -1;
    ...
```

Что здесь принципиально важно (переносится во все ПБЭ):

1. `GetBit(IN := ..., N := ...)` — **именованные аргументы**, `IN` — целое (маска), `N` — номер бита. Возврат — `BOOL`.
2. Входная маска хранится в параметре `АварияКрит1`. Тип — **DINT** (по ТЗ: «для масок, использующих в образце DINT, этот тип сохраняется»).
3. `ВариантАварий` — селектор варианта разбора аварий; значение `0` приводится к `1` (нумерация вариантов идёт с 1). Вариант `4` — «маска DINT + отдельные точки вентиляторов». Значит, у одного типа ПБЭ **несколько вариантов источника аварий**, а разбор зависит от варианта.
4. Отдельные BOOL-аварии и маска **сосуществуют** («Аварии вентиляторов приходят и отдельными точками»), но разбор маски от этого не отменяется.
5. `КодАварии` = первый (младший) установленный бит, `-1` если аварий нет. `КодПредупр` = `-1`, `ЕстьПредупр` = BOOL-признак предупреждения.
6. Локальные переменные объявляются в `VAR ... END_VAR` **внутри** программы; обращение к параметрам — через `.Value`.

### Рисунок А.4 — входящие и исходящие связи в окне «Настройки»

* Секция «Входящие связи»: одна связь, ссылка вида `Библиотеки.Локальная.Объекты.АОВ.Ре…`.
* Секция «Исходящие связи»: одна связь с тем же префиксом.
* Флажок «Использовать вход…» — включён.
* Секция «Текст»: `Цвет текста` = `#202020` (для **текста** используется шестнадцатеричный код; `rgb()` — именно в конвертерах/цветах заливки).
