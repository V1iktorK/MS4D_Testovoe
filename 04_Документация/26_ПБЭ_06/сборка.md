# ПБЭ № 6. Инструкция по сборке в MasterSCADA 4D 1.3.10.34633

**Кто выполняет:** пользователь. Материал — этот документ плюс `параметры.md`, `окна_и_связи.md`, `st/Программа_ST_1.st`, `21_ПБЭ_01/планировщик.md`.
**Что получится:** библиотечный элемент вытяжной установки Carel µAria с 13 окнами, групповыми командами шкафа, задержками тревог и индикацией осн./резерв.
**Оценка времени:** ≈ 24,5 ч (при сборке копированием из ПБЭ № 7 — ≈ 12 ч).

> **Главный принцип.** ПБЭ № 6 — **вытяжной аналог ПБЭ № 7**. Оба на Carel µAria, оба без разбора масок и без влажности. Поэтому основная работа — копирование ПБЭ № 7 плюс **три добавления** и **одно удаление**.

### 5.5. Логика в программе — раздел 4
Реализована **счётчиком секунд**, а не библиотечными `TON`/`TOF`:
```
ТаймерКрит := ТаймерКрит + ШагПрограммыСек;
IF ТаймерКрит >= СекТревоги THEN ТревогаПодтверждена := TRUE; END_IF;
```

> **Почему не `TON`.** Типы `MasterSCADA.Program.FB.TON` и `.TOF` в перечне подтверждены, но **форма объявления экземпляра функционального блока с состоянием** в ST этой сборки документально не подтверждена. Собственный счётчик не зависит от этой формы (допущение `D-62`).
>
> **Если среда поддерживает экземпляры ФБ** — заменить блок на `TON(IN := …, PT := …)`, сохранив параметры. Поведение идентично.

## Шаг 9. Групповые связи (1 ч)

Групповые параметры требуют **подключения к общим тегам шкафа**. ДИГАМ подключает один экземпляр группы, остальные получают то же значение.

**Что должен сделать ДИГАМ (или вы при настройке тестового проекта):**
1. Выбрать **один** экземпляр группы как «ведущий» (например В1 для ШУВ1, В2.1 для ШУВ2).
2. Подключить его групповые параметры (`ГрВклШкафа`, `ГрСтопШкафа`, `ГрРаботаШкафа`, `ГрАварияШкафа`, …) к тегам шкафа.
3. Остальные экземпляры группы — либо получить те же значения от ДИГАМ, либо связать с параметрами ведущего экземпляра.

> **Внимание.** **Проверка при сборке:** групповые параметры **не должны быть автоматически связаны** между экземплярами — это делает ДИГАМ при интеграции (ТЗ п. 1.5).

## Частые ошибки и что делать

| Симптом | Причина | Решение |
|---|---|---|
| **Авария срабатывает мгновенно** | задержки не реализованы или `НастрФункцияЗадержки = FALSE` | проверить раздел 4 программы и настройку |
| **Кратковременный признак даёт тревогу** | задержка есть, но `ЗадержкаТревоги = 0` | задать ≥ 10 с |
| Задержка срабатывает не через то время | `ШагПрограммыСек` не соответствует фактическому циклу | шаг 10 |
| **Ротация переключает вентиляторы** | скопировали логику из ПБЭ № 2 | **удалить** — ТЗ для № 6 её не требует (?) |
| **Групповые параметры продублировали индивидуальные** | невнимательное копирование | привести к `параметры.md` §2 (тест T6-16) |
| Групповая команда подменяет индивидуальную | неверная трактовка ТЗ | команда **дополняет**, не подменяет |
| Расписание перебивает шкаф | неверный приоритет источников | ОПЕРАТОР > ШКАФ > РАСПИСАНИЕ |
| В мнемосхеме остался калорифер или ККБ | скопировали из ПБЭ № 1/7 | удалить — это приточные узлы (?) |
| Осталась влажность | не выполнен шаг 3.1 | удалить параметры, группы, сообщение |
| В программе есть `GetBit` | скопировали из ПБЭ № 1 | заменить из файла ПБЭ № 6 |
| Ошибка на `TIME_TO_INT` | иное имя | возможно `TIME_TO_DINT`; сообщить мне |
| Ошибка на `:= 0` для TIME | нужен явный литерал | `T#0s` |
| День недели планировщика неверен | не подключены `СистемаДеньНеделиТекст`, `СистемаЧас`, `СистемаМин` | подключить к системному тегу времени |
| Норма и авария перепутаны | `True` первой строкой | `False` первой |
| Цвет `#RRGGBB` в конвертере | не соблюдено требование | `rgb(...)` |

## Что даёт этот ПБЭ остальным

После ПБЭ № 6 в комплекте три «донора»:

| Донор | Для кого | Почему |
|---|---|---|
| **ПБЭ № 1** | приточные | полный набор: маски DINT + BOOL + планировщик |
| **ПБЭ № 7** | приточные на µAria | нет разбора масок |
| **ПБЭ № 6** | **ПБЭ № 8** (Zentec M245, вытяжка корпуса 22) | **вытяжная** мнемосхема + задержки тревог + групповые команды — всё это нужно и № 8 |

Для **ПБЭ № 8** копировать **ПБЭ № 6**: останется заменить контроллер (µAria → Zentec M245), добавить имена аварий **A001–A007** и команду **сброса зуммера**.
