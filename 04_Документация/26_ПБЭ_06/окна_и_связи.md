> **Основание для переноса.** ПБЭ № 6 — вытяжной аналог ПБЭ № 7 (оба на Carel µAria, оба без разбора масок и без влажности). Копирование ПБЭ № 7 с тремя изменениями:
> 1. **Мнемосхема приточная → вытяжная**, удалены приточные узлы.
> 2. **Добавлены групповые параметры** (общий шкаф управления).
> 3. **Добавлены задержки тревог и расширенная индикация осн./резерв.**

### 8.2. Ключевые технические решения

| Решение | Обоснование |
|---|---|
| **Задержка собственным счётчиком, а не `TON`/`TOF`** | Типы ФБ подтверждены, но форма объявления экземпляра с состоянием — нет. Счётчик не зависит от этой формы (допущение `D-62`) |
| **Три отдельные задержки** | Подтверждение при появлении и отпускание при исчезновении — разные физические величины; одно значение не покрывает оба случая |
| **Задержка применяется к группе признаков** | 25 раздельных счётчиков дали бы 25 дополнительных параметров без требования ТЗ (допущение `D-62b`). `КолТревогВЗадержке` — грубая оценка |
| **Приоритет источников: ОПЕРАТОР > ШКАФ > РАСПИСАНИЕ** | ТЗ приоритеты не задаёт. Выбран безопасный для эксплуатации порядок (допущение `D-71`) |
| **Групповая команда дополняет индивидуальную** | ТЗ: «общие команды группы обозначаются отдельно». Подмена индивидуального управления групповым лишила бы оператора управления установкой |
| **Ротация НЕ реализована** | ТЗ прил. 1 ч. 2 для № 6 требует **индикации**, а ротация — требование № 2 (допущение `D-80`). Моточасы ведутся для индикации распределения наработки |
| **АВР только при аварии основного** | Не ротация, а резервирование — то, что требуется |
| **Готовность вентилятора** | `ГотовВент*` = нет аварии И нет потери связи с вентилятором И общая связь есть |

### 8.3. Форма кавычек и имена аргументов
Двойные кавычки; `LIMIT(MN := …, IN := …, MX := …)`; `TIME_TO_INT(IN := …)`. Время читается входными параметрами `СистемаДеньНеделиТекст`, `СистемаЧас`, `СистемаМин`.
