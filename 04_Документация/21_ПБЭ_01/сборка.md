### 2.1.1. (?) Три параметра времени — обязательны (уточнение по среде)

Проверено: **функции получения текущего времени в среде НЕТ** (`GET_LOCAL_TIME` отсутствует). Поэтому планировщик **принимает** день недели и время суток извне:

| Параметр | Тип | Направление | Значения |
|---|---|---|---|
| `СистемаДеньНеделиТекст` | STRING | **Вх** | `Пн` … `Вс` |
| `СистемаЧас` | INT | **Вх** | 0…23 |
| `СистемаМин` | INT | **Вх** | 0…59 |

**Что делать при сборке:**
1. Создать эти три параметра.
2. **Подключить их к системному тегу времени** — в тестовом проекте это делаете вы, в рабочем проекте ДИГАМ.
3. **Проверить:** при работающем планировщике `ТекущийИнтервал` меняется по часам суток.

> **Если системного тега времени в проекте нет** — сообщите мне. Тогда потребуется отдельная программа формирования дня недели и времени в проекте ДИГАМ; логика ПБЭ при этом **не изменится** (параметры останутся теми же, изменится только источник).

### 2.2. Критично проверить типы (ключевые места)

| Параметр | Тип | Почему критично |
|---|---|---|
| **`АварияКрит1`** | **DINT** | ТЗ п. 3 — «для масок, использующих в образце DINT, этот тип сохраняется» |
| **`АварияПредуп1`** | **DINT** | то же |
| `КолАварий` | INT | результат цикла подсчёта бит |
| `КодАварии`, `КодПредупр` | INT | значение `-1` при отсутствии |
| `ЗадVПритока`, `ЗадVВытяжки` | INT | целые проценты |
| `Т*`, `Вл*`, `Положение*`, `VФакт*` | REAL | вещественные |
| Все `Вр…` | TIME | времена |
| `План…НачалоЧ/Мин`, `КонецЧ/Мин` | INT | часы и минуты |
| `План…УставкаT` | REAL | температура |
| `План…УставкаV` | INT | процент |
| `План…Активация` | BOOL | флажок |

### 2.3. Создание планировщика (121 параметр)
**Способ:** создать блок для «Понедельник, интервал 1» (8 параметров), затем **копировать и переименовывать**, меняя `<День><Интервал>`.

Порядок имён (14 блоков):
`Пн1, Пн2, Вт1, Вт2, Ср1, Ср2, Чт1, Чт2, Пт1, Пт2, Сб1, Сб2, Вс1, Вс2`.

Диапазоны (свойства `Минимум`/`Максимум`):

| Поле | Мин | Макс | По умолч. |
|---|---|---|---|
| `Активация` | — | — | FALSE |
| `РежимРаботы` | 0 | 2 | 0 |
| `НачалоЧ` | 0 | **23** | 8 |
| `НачалоМин` | 0 | **59** | 0 |
| `КонецЧ` | 0 | **23** | 17 |
| `КонецМин` | 0 | **59** | 0 |
| `УставкаT` | 5 | 40 | 20 |
| `УставкаV` | 0 | 100 | 50 |

> **Внимание.** **Часы — максимум 23, минуты — 59.** В образце (рис. А.5) стоит `Максимум = 100` — это для общих полей. Оставить 100 для часа значит позволить ввести «25:70». Тест **T1-48**.

**Проверка шага:** ≈ 306 параметров. **Тесты:** T1-10, T1-70 частично.

1. `Ресурсы → Программы` → `Программа_ST_1`, язык ST.

### 4.1. Проверить после вставки

| Что | Ожидание |
|---|---|
| Раздел 0 | `ВариантОборудования = 3` гасит `НастрЕстьВлажность` и `НастрРазборМаски` |
| Раздел 2 | `GetBit(IN := АварияКрит1.Value, N := 0…8)`; цикл `FOR i := 0 TO 8 DO` даёт `n` и `k` |
| Раздел 2 | биты 5 и 6 **не** разбираются в отдельные параметры |
| Раздел 3 | три подраздела: критические всегда / критические по составу / **предупредительные** |
| Раздел 3 | `КолАварий := n + КритОтд` |
| Раздел 4 | **День недели и время суток читаются из входных параметров** `СистемаДеньНеделиТекст`, `СистемаЧас`, `СистемаМин`; затем ограничиваются; затем `ТекСек` |
| Раздел 4 | `ТекущийИнтервал` = 2 / 1 / -1; приоритет у 2 |
| Раздел 4 | применение к `Включена`, `ЗадТПритока`, `ЗадVПритока`, `ЗадРежима` — **только параметры ПБЭ** |
| Раздел 4 | подавление при `ЗадРежима = 1`, `Блокировка`, `ДиагНетСвязи` |
| Везде | **ни одной** записи в тег контроллера |

### 4.2. Возможные ошибки компиляции

| Ошибка | Причина | Решение |
|---|---|---|
| `DT_TO_STRING` неизвестна | **функция удалена** — не должна встречаться в коде | если ошибка есть, заменить программу из файла |
| `GET_LOCAL_TIME` неизвестна | **функция удалена** — не должна встречаться в коде | если ошибка есть, заменить программу из файла |
| `MID` — иные аргументы | в сборке могут быть `STR/LEN/POS` | сообщить мне |
| Ошибка на `'Пн'` | требуются двойные кавычки | заменить **все** литералы (60+) и сообщить |
| Ошибка на `LIMIT` | иные имена аргументов | сообщить мне |
| «Тип несовместим» на `АварияКрит1` | объявлен не DINT | переделать тип на DINT |
| «Неизвестный идентификатор `ПредупрОтд`» | потеряно объявление в `VAR` | проверить блок `VAR` в начале файла |
| Ошибка на `ПланЗадT` | параметр не создан | создать (§11.3) |
| «Неизвестный идентификатор `НастрПлан…`» | не созданы 4 настройки | создать (§2) |

> **Разбор дня недели больше не зависит от формата строки даты.** Функции получения текущего времени в среде **нет** (проверено), поэтому день недели и время суток принимаются **входными параметрами** `СистемаДеньНеделиТекст`, `СистемаЧас`, `СистемаМин`. **При сборке нужно подключить эти три параметра к системному тегу времени** — их подключает ДИГАМ, либо вы в тестовом проекте.

**Проверка шага:** программа компилируется. **Тесты:** T1-17, T1-18, T1-45.

## Частые ошибки и что делать

| Симптом | Причина | Решение |
|---|---|---|
| **`АварияКрит1` объявлен как INT/REAL** | невнимательность | сменить тип на **DINT** (?) |
| Создан отдельный параметр для бита 5 или 6 | не прочитан рис. А.2 | **удалить**: вентиляторы приходят отдельными точками |
| Разбор масок работает для µAria | не выставлен `НастрРазборМаски` | программа должна гасить его при `ВариантОборудования = 3` |
| Влажность видна для µAria | не выставлен `НастрЕстьВлажность` | то же |
| Нет кнопки «РАСПИСАНИЕ» | скопировали панель из ПБЭ № 3 | **добавить** — у № 1 она обязательна |
| Нет окна 1.4 | перепутали с ПБЭ № 2/3 | добавить окно «Планировщик» |
| Поля планировщика без исходящей связи | забыли вторую связь | у всех 112 полей — **обе** связи |
| `Максимум = 100` у часов | скопировали из образца | поставить **23** (минуты — **59**) |
| Имена объектов планировщика вида `Пн1_НачалоЧ` | отступили от схемы образца | привести к `1 Понедельник 1 Начало час` |
| Планировщик пишет в теги | неверная трактовка ТЗ | команды **только** через параметры ПБЭ |
| Расписание «перебивает» оператора | нет проверки `ЗадРежима <> 1` | добавить в условие применения |
| Двойное срабатывание на стыке интервалов | использовано `<=` для конца | конец **не включается**: `ТекСек < КонСек` |
| День недели определяется неверно | не подключены `СистемаДеньНеделиТекст`, `СистемаЧас`, `СистемаМин` | подключить к системному тегу времени |
| Ошибка на `LIMIT` | иные имена аргументов | имена `MN/IN/MX` подтверждены как верные; сообщить мне, если ошибка осталась |
| Норма и авария перепутаны | `True` первой строкой | `False` первой |
| Цвет не применился | `#RRGGBB` в конвертере | заменить на `rgb(...)` |
