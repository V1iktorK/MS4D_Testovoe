# ПБЭ № 1. Таблица параметров

Направление: **Вх** — приём из канала; **Вых** — формируется ПБЭ; **Настр** — настройка экземпляра; **Выч** — вычисляемое в ПБЭ.

> **Объём.** ПБЭ № 1 — самый крупный: три варианта оборудования, разбор масок, 14 флагов состава и **полный планировщик** (7 дней × 2 интервала × 11 параметров = 154 параметра планировщика). Итого **318 параметров**.

---

| № | Параметр | Тип | Напр. | Значения | Описание |

| 4 | `Помещение1` | STRING | Настр | — | Обслуживаемое помещение 1 |
| 5 | `Помещение1Назначение` | STRING | Настр | — | Назначение помещения 1 |
| 6 | `Помещение2` | STRING | Настр | — | Обслуживаемое помещение 2 |
| 7 | `Помещение2Назначение` | STRING | Настр | — | Назначение помещения 2 |
| 8 | `Помещение3` | STRING | Настр | — | Обслуживаемое помещение 3 |
| 9 | `Помещение3Назначение` | STRING | Настр | — | Назначение помещения 3 |
| 10 | `Помещение4` | STRING | Настр | — | Обслуживаемое помещение 4 |
| 11 | `Помещение4Назначение` | STRING | Настр | — | Назначение помещения 4 |
| 12 | `НомРасходаПритока` | REAL | Настр | 0…100000 м³/ч | Номинальный расход притока |
| 13 | `НомРасходаВытяжки` | REAL | Настр | 0…100000 м³/ч | Номинальный расход вытяжки |
| 14 | `СистемаДеньНеделиТекст` | STRING | **Вх** | `Пн` … `Вс` | **Текущий день недели** для планировщика. Подключается к системному тегу времени |
| 15 | `СистемаЧас` | INT | **Вх** | 0…23 | **Текущий час** для планировщика |
| 16 | `СистемаМин` | INT | **Вх** | 0…59 | **Текущие минуты** для планировщика |

> **Внимание.** **Важно (уточнение по среде, допущение `D-61` снято).** Штатной функции получения текущего времени в среде **нет** — функция `GET_LOCAL_TIME` отсутствует. Поэтому день недели и время суток принимаются **входными параметрами**, как любая другая внешняя величина. Это соответствует ТЗ п. 3: «Элемент работает со своими параметрами, без подключения к конкретному контроллеру». ДИГАМ подключает эти три параметра к системному тегу времени в рабочем проекте.
>
> Значения ограничиваются программой: `СистемаЧас` → 0…23, `СистемаМин` → 0…59.
