# ПБЭ № 3. Паспорт

## 1. Идентификация

| Параметр | Значение |
|---|---|
| **Номер ПБЭ по Перечню** | 3 |
| **Наименование по Перечню** | Заготовка универсального ПБЭ вытяжной установки для последующего применения с ШУВ-К, корпус 3 |
| **Граница экземпляра** | Один будущий экземпляр — одна вытяжная установка |
| **Область применения** | Вытяжные установки, подключаемые к ШУВ-К. Фактический состав уточняется при включении шкафа в работу |
| **Количество экземпляров** | «При вводе ШУВ-К в работу» — на текущем этапе **0** |
| **Количество окон** | **12** (позиции 3.1–3.12) |
| **Роль** | **Заготовка.** Окна, параметры отображаемых значений, элементы управления, внутренние связи |
| **Приоритет разработки** | 2-й |

## 2. Назначение

ПБЭ предназначен для последующего применения с шкафом управления вытяжной вентиляцией ШУВ-К корпуса № 3. По результатам обследования **ШУВ-К находится в резерве**, поэтому на текущем этапе тип разрабатывается как заготовка: создаётся каркас — окна, параметры, элементы управления и внутренние связи, — который проверяется на тестовых значениях и впоследствии наполняется фактическими сигналами при включении шкафа в работу.

## 4. Что предусмотрено ТЗ

Из ТЗ, приложение 1, часть 2 (ПБЭ № 3):

> «ПБЭ № 3 — заготовка универсального библиотечного элемента вытяжной установки для последующего применения с ШУВ-К. По результатам обследования ШУВ-К находится в резерве.
> На текущем этапе исполнитель разрабатывает 12 окон по позициям 3.1–3.12, создаёт параметры для отображаемых значений и элементов управления, настраивает внутренние связи графики с этими параметрами. Работа окон и связей проверяется на тестовых значениях в проекте разработки.
> Реализация полного набора переменных ШУВ-К, обработки данных его приводов, логики резерва, общих команд шкафа и назначения входов Q7…QB на текущем этапе не требуется. Планировщик и кнопка «РАСПИСАНИЕ» отсутствуют.
> Один будущий экземпляр соответствует одной вытяжной установке. Состав подключаемых сигналов, необходимая программная обработка и количество экземпляров уточняются при включении ШУВ-К в работу.»

Из ТЗ, приложение 2:

> «Кнопка «РАСПИСАНИЕ» предусмотрена для ПБЭ № 1, 6, 7 и 8; в ПБЭ № 2 и № 3 она отсутствует.»
> «Для ПБЭ № 1 и № 7 применяется приточная мнемосхема; для № 2, 3, 6 и 8 — вытяжная.»
> «Для вытяжных ПБЭ набор узлов приточной установки из образца не переносится автоматически: отображаются узлы, предусмотренные для соответствующих установок.»

## 7. Настройки экземпляра (заготовка для будущего включения)

| Настройка | Тип | Назначение |
|---|---|---|
| `Название` | STRING | Обозначение установки |
| `Обозначение` | STRING | Код установки (например `В1`) |
| `Корпус` | INT | Номер корпуса (3) |
| `Шкаф` | STRING | Обозначение шкафа (`ШУВ-К`) |
| `Помещение1…3` | STRING | Обслуживаемые помещения |
| `Помещение1…3Назначение` | STRING | Назначения помещений |
| `ВариантОборудования` | INT | Вариант исполнения — под будущее уточнение состава |
| `НастрЕстьЗаслонкаПриток` | BOOL | Есть заслонка притока |
| `НастрЕстьЗаслонкаВытяж` | BOOL | Есть заслонка вытяжки |
| `НастрЕстьФильтр` | BOOL | Есть фильтр |
| `НастрЕстьВент1` | BOOL | Есть вентилятор 1 |
| `НастрЕстьВент2` | BOOL | Есть вентилятор 2 (резервный) |
| `НастрЕстьНагреватель` | BOOL | Есть нагреватель |
| `НастрЕстьТПомещения` | BOOL | Есть датчик температуры помещения |
| `НастрЕстьТНарВозд` | BOOL | Есть датчик температуры наружного воздуха |

> Набор настроек — **заготовка** под уточнение состава при вводе ШУВ-К в работу (`D-30`). При получении фактического состава добавляются/удаляются признаки; структура окон и связей при этом не меняется — скрытие выполняется входящей связью на «Видимость».
