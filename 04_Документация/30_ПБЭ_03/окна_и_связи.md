## 8. Программа ST

### 8.1. Что делает программа и чего не делает

| Делает | Не делает |
|---|---|
| Ограничивает вводимые уставки (`LIMIT`) | Не реализует полный набор переменных ШУВ-К |
| Формирует зеркальный признак `Отключена` | Не обрабатывает данные приводов ШУВ-К |
| Гасит команды отключённых настройкой функций | Не реализует логику резерва |
| Формирует тексты состояний заслонок | Не формирует общие команды шкафа |
| Пересчитывает % → расход | Не использует назначение входов Q7…QB |
| Формирует аварии/предупреждения, коды `-1` | **Не разбирает битовые маски** |
| Формирует состояние установки по приоритету | Не управляет планировщиком (его нет) |

### 8.2. Полный текст программы

Полный текст — в файле `st/Программа_ST_1.st`. Разделы программы:

| Раздел | Содержание |
|---|---|
| 1 | Ограничение уставок — `LIMIT` и ручные границы для целых |
| 2 | Зеркальный признак `Отключена` |
| 3 | Команды отключённых функций не формируются; взаимоисключение пуск/стоп |
| 4 | Тексты состояний заслонок |
| 5 | Пересчёт `%` → `м³/ч` |
| 6 | Аварии и предупреждения, коды `-1` |
| 7 | Состояние установки по приоритету, тексты, состояние системы |

### 8.3. Пояснения к ключевым местам

| Место | Пояснение |
|---|---|
`LIMIT(MN := …, IN := …, MX := …)` | Ограничение диапазона вводимых уставок (правило T-12). Именованные аргументы — как `GetBit(IN := …)` на рис. А.2 |
| Команды взаимоисключаются | Если оператор нажал и «Пуск», и «Стоп» — приоритет отдаётся «Стоп» (снимается «Пуск»). Это каркасное правило, не логика ШУВ-К |
| `IF NOT НастрЕстьВент2 THEN ПускВент2 := FALSE` | Требование ТЗ п. 1.3: команды по отключённым функциям не формируются |
| Аварии отдельными BOOL | ТЗ п. 3: разбор масок не делается, потому что масок нет |
| `ЕстьАвария := (v > 0) AND NOT ДиагНетСвязи` | Потеря связи не маскируется под аварию |
| Коды `-1` | По образцу рис. А.2: `IF n = 0 THEN КодАварии.Value := -1; END_IF;` |
| Приоритет состояния | Авария → Нет связи → Предупреждение (блокировка) → Работа → Стоп |
| Расход `%` → `м³/ч` | `РасходВытяжки := VВытяжки * НомРасходаВытяжки / 100.0`. При нулевом номинале расход нулевой |

### 8.4. Форма кавычек в строковых литералах
В файле использованы **одинарные** кавычки (`'Стоп'`). В образце (рис. А.2) строковых литералов нет, поэтому форма документально не подтверждена. **Если компилятор требует двойные** — заменить во всём файле (в файле 20 литералов) и сообщить мне: внесу форму в шаблон для остальных 7 ПБЭ.
