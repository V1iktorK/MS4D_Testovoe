# ПБЭ № 3. Таблица параметров

Направление: **Вх** — приём из канала (подключает ДИГАМ); **Вых** — значение, формируемое ПБЭ; **Настр** — настройка экземпляра; **Выч** — вычисляемое внутри ПБЭ.

> **Область разработки (ТЗ прил. 1 ч. 2).** ПБЭ № 3 — заготовка. Создаются параметры для **отображаемых значений** и для **элементов управления**, настраиваются **внутренние связи графики**. Полный набор переменных ШУВ-К, обработка данных приводов, логика резерва, общие команды шкафа и входы Q7…QB — **не разрабатываются**.
>
> Поэтому ниже описаны параметры каркаса вытяжной установки. Состав подключаемых сигналов уточняется при вводе ШУВ-К в работу (`D-30`); при уточнении **добавляются или удаляются строки §4–§6**, структура окон и связей не меняется.

## 2. Признаки состава оборудования (настройки экземпляра)

При `FALSE` соответствующая графика скрывается входящей связью на свойство **«Видимость»**, а команда по отключённой функции не формируется (ТЗ п. 1.3).

| № | Параметр | Тип | Напр. | По умолч. | Что скрывает / отключает |
|---|---|---|---|---|---|
| 20 | `НастрЕстьЗаслонкаПриток` | BOOL | Настр | TRUE | Группа графики заслонки притока |
| 21 | `НастрЕстьЗаслонкаВытяж` | BOOL | Настр | TRUE | Группа графики заслонки вытяжки |
| 22 | `НастрЕстьФильтр` | BOOL | Настр | TRUE | Группа графики фильтра |
| 23 | `НастрЕстьВент1` | BOOL | Настр | TRUE | Группа графики вентилятора 1 |
| 24 | `НастрЕстьВент2` | BOOL | Настр | FALSE | Группа графики вентилятора 2 (резервный). Кнопки пуска/останова В2 |
| 25 | `НастрЕстьНагреватель` | BOOL | Настр | FALSE | Группа графики нагревателя и его уставки |
| 26 | `НастрЕстьТПомещения` | BOOL | Настр | TRUE | Строка «Температура помещения» в панели аналоговых значений и сигнал тренда |
| 27 | `НастрЕстьТНарВозд` | BOOL | Настр | TRUE | Строка «Температура наружного воздуха» и сигнал тренда |

> **Почему `НастрЕстьВент2 = FALSE` и `НастрЕстьНагреватель = FALSE` по умолчанию:** состав узлов ШУВ-К не определён (`D-30`). Значение `FALSE` означает «не показывать, пока не подтверждено». При уточнении состава выставляется `TRUE`.

Никакой связи команд с реальными приводами ШУВ-К здесь не создаётся: подключение выполнит ДИГАМ при вводе в работу.

## 13. Резервные параметры (объявлены, но ПБЭ не использует)

Параметры ниже присутствуют в перечне сигналов оборудования, поэтому объявлены в таблице,
но **не участвуют** ни в программе, ни в привязках окон, трендов и сообщений.
Они создаются «на будущее» либо не создаются вовсе — решение принимает сборщик.
Такие параметры отмечены как резервные — это не ошибка: ошибкой считается только
вычисляемый параметр, который программа не заполняет.

| Параметр | Почему не используется |
|---|---|
| `Помещение1Назначение` | Назначение помещения. Берётся из справочника по номеру помещения, отдельным параметром не используется (то же решение, что §6.2 в ПБЭ № 5). |
| `Помещение2Назначение` | Назначение помещения. Берётся из справочника по номеру помещения, отдельным параметром не используется (то же решение, что §6.2 в ПБЭ № 5). |
| `Помещение3Назначение` | Назначение помещения. Берётся из справочника по номеру помещения, отдельным параметром не используется (то же решение, что §6.2 в ПБЭ № 5). |
