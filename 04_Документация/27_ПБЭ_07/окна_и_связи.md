# ПБЭ № 7. Окна, карта связей и программная обработка

**Тип мнемосхемы: ПРИТОЧНАЯ** (ТЗ прил. 2: «для ПБЭ № 1 и № 7 применяется приточная мнемосхема»).
**13 окон.** Нумерация **полностью повторяет ПБЭ № 1** (1.1 ↔ 7.1 … 1.13 ↔ 7.13).

> **Основание для переноса.** ТЗ прил. 1 ч. 2: «Состав параметров и функций — как у варианта Carel µAria ПБЭ № 1». Поэтому окна ПБЭ № 7 получаются из окон ПБЭ № 1 **копированием** с тремя правками:
> 1. **Удалить всё, что касается влажности и увлажнителя** — влажность для µAria не выводится.
> 2. **Удалить всё, что касается разбора масок** — маски не используются.
> 3. **Добавить группу `Гр_НагревОхлаждение`** с селектором `ЗадНагревОхлаждение` — специфика µAria.
>
> Всё остальное совпадает. Полные эскизы и карты связей — в `21_ПБЭ_01/окна_и_связи.md`; здесь приведены **отличия и полные таблицы для изменённых мест**, чтобы артефакт был самодостаточен.

## 9. Программа ST

### 9.1. Отличия от программы ПБЭ № 1

| Что | ПБЭ № 1 | ПБЭ № 7 |
|---|---|---|
| Раздел 0 «выбор варианта» | есть | **удалён** — один контроллер |
| Раздел 2 «разбор масок» | есть (17 строк `GetBit`) | **удалён полностью** |
| `n`, `k`, `i` в `VAR` | есть | **удалены** — разбирать нечего |
| `КолАварий` | `n + КритОтд` | **`КритОтд`** |
| Код аварии | младший бит маски или 100 | **1 при наличии, −1 при отсутствии** |
| Влажность | есть (`НастрЕстьВлажность`) | **нет ни одной строки** |
| Группа `Ав…` для нагрев/охлаждение | нет | **есть** (раздел 2) |
| Планировщик (раздел 4) | есть | **идентичен** |
| АВР и команды (раздел 5) | есть | **идентичны** |

### 9.2. Структура (8 разделов, 686 строк)

| Раздел | Содержание |
|---|---|
| 1 | Ограничение вводимых уставок |
| 2 | **Команда переключения нагрев/охлаждение** (специфика µAria) |
| 3 | **Аварии отдельными логическими признаками** (3.1 критические всегда, 3.2 по составу, 3.3 предупредительные) |
| 4 | **Планировщик** (4.1 время, 4.2 активный интервал по дню, 4.3 приоритет интервала 2, 4.4 применение к параметрам ПБЭ) |
| 5 | Управление, АВР, команды, сезон |
| 6 | Состояния узлов текстом |
| 7 | Расход |
| 8 | Состояние установки по приоритету |

### 9.3. Контроль по ТЗ

| Требование | Как выполнено |
|---|---|
| **Разбор масок не делается** | В программе **нет** вызова `GetBit`. В параметрах **нет** DINT-масок. Тест **T7-06** |
| Текст аварии формируется по признаку | `КодАварии` = 1 при наличии любого признака; текст — по параметру-признаку (ТЗ п. 3) |
| Влажность не выводится | Параметров влажности нет; в программе — ни одной строки о влажности |
| Планировщик по п. 3.2 | Раздел 4 идентичен ПБЭ № 1 |
| Команды только через параметры ПБЭ | Раздел 4.4 воздействует на `Включена`, `ЗадТПритока`, `ЗадVПритока`, `ЗадРежима` |
| Команда нагрев/охлаждение | `ЗадНагревОхлаждение`, ограничение 0…2, запрет охлаждения без ККБ |

### 9.4. Форма кавычек
Использованы **одинарные** кавычки (`'Пн'`, `'Стоп'`, `'Открыта'` и др.). Если компилятор требует двойные — заменить во всём файле и сообщить мне.
