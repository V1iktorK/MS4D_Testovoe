# ПБЭ № 7. Паспорт

## 1. Идентификация

| Параметр | Значение |
|---|---|
| **Номер ПБЭ по Перечню** | 7 |
| **Наименование по Перечню** | Универсальный ПБЭ приточной установки — Carel µAria, корпус 22 |
| **Граница экземпляра** | Один экземпляр — **одна приточная установка** |
| **Экземпляры** | П-1, П-2, П-3 → **3** |
| **Количество окон** | **13** (позиции 7.1–7.13) |
| **Система применения** | Корпус № 22 |
| **Контроллер** | Carel µAria |
| **Роль** | Приточная установка. Реализуется на основе варианта µAria ПБЭ № 1 |
| **Приоритет разработки** | 5-й |

**Сверка количества экземпляров:** Перечень даёт П-1, П-2, П-3 → **3 экземпляра**. Совпадает с ТЗ прил. 1 ч. 2.

## 2. Назначение

Универсальный тип для приточных установок корпуса № 22 под управлением Carel µAria. Обеспечивает отображение состояния установки и узлов, приём аварий **отдельными логическими признаками**, уставки температуры и скорости, команды пуска, сброса аварий и переключения нагрев/охлаждение, планировщик, тренды и архивирование.

## 5. Соответствие параметров ПБЭ № 1 (вариант µAria)

ТЗ требует **тот же состав**, поэтому таблица параметров ПБЭ № 7 — это подмножество ПБЭ № 1, ограниченное вариантом µAria.

### 5.1. Сохраняется полностью (имена и типы идентичны)

| Группа | Количество | Примечание |
|---|---|---|
| Общие (название, обозначение, корпус, помещения, расход) | 13 | `Корпус = 22` |
| **Планировщик** | **121** | схема `План<День><Интервал><Поле>` — идентична |
| Команды (включая **`ЗадНагревОхлаждение`**) | 12 | нагрев/охлаждение — специфика µAria |
| Состояния | 22 | |
| Аварии отдельными BOOL | 25 | |
| Дискретные сигналы узлов | 27 | |
| Аналоговые сигналы | 22 | |
| Уставки и задания | 22 | |
| Настройки состава и планировщика | 20 | |

### 5.2. Исключается полностью (специфика pCO XS / c.pCO)

| Исключено | Почему |
|---|---|
| `АварияКрит1` (DINT) | µAria передаёт аварии отдельными BOOL. **Маска не создаётся**, разбор не выполняется (ТЗ п. 3) |
| `АварияПредуп1` (DINT) | то же |
| `ВариантАварий` | нечего разбирать |
| `НастрРазборМаски` | разбор не выполняется — флага не требуется |
| `НастрЕстьВлажность` | **влажность для µAria не выводится** (ТЗ прил. 1 ч. 2) |
| `НастрЕстьУвлажнитель` | следствие предыдущего |
| `ВлПритока`, `ВлПомещения` | не выводятся |
| `РаботаУвлажнителя`, `АвУвлажнитель` | нет увлажнителя |
| `ЗадВлажности`, `УвлКонтурАктивирован`, `РежимУвлажнителя`, `ПроизвУвлажнителяРучн` | нет увлажнителя |
| Группа «Пароувлажнитель» в окне 7.3 | нет увлажнителя |
| Строки влажности в панелях окон 7.1, 7.2, 7.5, 7.6 | нет влажности |
| Разобранные биты маски (`Пожар` из маски, `АвЗаслВыт`, `АвЗаслПрит`, `АвПолохЗаслРецВыт`, `АвПолохЗаслРецПрит`, `НизкаяТПомещения`, `ОбрывТПомещения`) | в структуре «из маски» отсутствуют. **Одноимённые признаки приходят от канала как отдельные BOOL** — см. §5.3 |

> **Важное уточнение по авариям.** Параметры `Пожар`, `АвЗаслВыт`, `АвЗаслПрит`, `АвПолохЗаслРецВыт`, `АвПолохЗаслРецПрит`, `НизкаяТПомещения`, `ОбрывТПомещения` в ПБЭ № 7 **сохраняются**, но с другим **направлением**: в ПБЭ № 1 для pCO XS/c.pCO они были **вычисляемыми** (результат `GetBit`), а здесь — **входными BOOL от канала**. Это и есть реализация нормы «аварии отдельными логическими признаками».

### 5.3. Параметры, меняющие направление

| Параметр | ПБЭ № 1 (pCO XS/c.pCO) | ПБЭ № 7 (µAria) |
|---|---|---|
| `Пожар` | Выч (из `GetBit` бита 0) | **Вх** (BOOL от канала) |
| `АвЗаслВыт` | Выч (бит 1) | **Вх** (BOOL) |
| `АвЗаслПрит` | Выч (бит 2) | **Вх** (BOOL) |
| `АвПолохЗаслРецВыт` | Выч (бит 3) | **Вх** (BOOL) |
| `АвПолохЗаслРецПрит` | Выч (бит 4) | **Вх** (BOOL) |
| `НизкаяТПомещения` | Выч (бит 7) | **Вх** (BOOL) |
| `ОбрывТПомещения` | Выч (бит 8) | **Вх** (BOOL) |
| `КолАварий` | `n + КритОтд` | `КритОтд` (без `n`) |

**Следствие:** задача разбора аварий в ПБЭ № 7 — «текст аварии формируется по признаку» (ТЗ п. 3). Программа не содержит `GetBit`.

## 8. Взаимодействие с остальными ПБЭ

| Связь | Описание |
|---|---|
| **С ПБЭ № 1** | **Прямая родственная.** ПБЭ № 7 = вариант µAria ПБЭ № 1, применённый к корпусу 22. Состав параметров и функций совпадает; отличие — в типе (отдельный элемент) и настройках |
| С ПБЭ № 8 | **Один корпус 22.** ПБЭ № 8 — вытяжные Zentec M245 того же корпуса. Разные вентустановки, пересечения по параметрам нет |
| С ПБЭ № 6 | Оба на Carel µAria; № 6 — вытяжка корпуса 8, № 7 — приток корпуса 22. Общий каркас, разные узлы и мнемосхемы |
| С ПБЭ № 2, 3, 4 | Общий каркас вытяжных ПБЭ и планировщика |
| С ПБЭ № 5 | Не пересекается (VRF) |

> **Почему ПБЭ № 7 — отдельный тип, а не экземпляр ПБЭ № 1.** ТЗ п. 1.1: «Для каждой позиции Перечня разрабатывается один универсальный тип ПБЭ». Позиция 7 — самостоятельная строка Перечня со своим наименованием («Carel µAria, корпус 22») и своим количеством экземпляров (3). Поэтому это отдельный тип, хотя состав параметров и заимствован у № 1.

## 10. Планировщик — заимствование

Планировщик ПБЭ № 7 **полностью совпадает** с планировщиком ПБЭ № 1:
* та же схема параметров `План<День><Интервал><Поле>` — 121 параметр;
* тот же алгоритм (полуинтервал, ночные интервалы, приоритет интервала 2);
* те же настройки применимости;
* команды формируются **только через параметры экземпляра** (ТЗ п. 3.2).

Полное описание — в `21_ПБЭ_01/планировщик.md`. Отличие только в номере окна (**7.4** вместо 1.4) и в подписях панели окна 7.1.
