**Тип мнемосхемы: ВЫТЯЖНАЯ** (ТЗ прил. 2: «для № 2, 3, 6 и 8 — вытяжная»).

> **Основание для переноса.** ПБЭ № 8 — вытяжной ПБЭ на другом контроллере (Zentec M245 вместо Carel µAria). Копирование ПБЭ № 6 с изменениями:
> 1. **Добавлены аварии A001–A007** отдельными признаками.
> 2. **Добавлен сброс зуммера** и признак «отключён оператором».
> 3. **Добавлены положения клапанов** с признаком «в промежуточном положении».
> 4. **Добавлено давление в воздуховоде** и задание давления.
> 5. **Уточнена группа:** `ГрКолУстановок` = 1 для шести установок, = 2 для В7 и В8.
>
> Групповые параметры (18 шт.), задержки тревог (3 шт.) и индикация осн./резерв. **переносятся из ПБЭ № 6 без изменений**.

### 8.2. Ключевые технические решения

| Решение | Обоснование |
|---|---|
| **Имена параметров = коды производителя** | `АвA001`…`АвA007`. ДИГАМ подключает теги Zentec **без переименования**. Тест T8-06 |
| **`CASE` по номеру первого кода** | Формирование `КодПервойАварии` — строки вида «A001». Не через `GetBit`: масок нет |
| **`CONCAT` для перечня кодов** | ТЗ п. 3: «текст аварии формируется по признаку». Собирается строка «A001 A004» |
| **Признак «в промежуточном положении»** | Для клапана вентиляции застревание между положениями — самостоятельная неисправность. Просто «не открыт и не закрыт» оператору ничего не говорит (допущение `D-81`) |
| **Сброс зуммера отделён от сброса аварий** | Это два разных действия оператора. «Сброс зуммера» = «я слышу, иду разбираться», авария **сохраняется**. Смешивать нельзя — это требование ТЗ («команды сброса аварий **и зуммера**») |
| **Признак `ЗуммерОтключенОператором` сбрасывается при снятии всех аварий** | Чтобы **следующая** авария снова включила зуммер. Иначе после первого сброса зуммер молчал бы всегда |
| **Промежуточное положение клапана — предупреждение, не авария** | Застревание клапана не останавливает установку, но требует внимания. Поэтому `ЕстьПредупр`, а не `ЕстьАвария` |
| **Ротация не реализована** | Требование только ПБЭ № 2 (допущение `D-80`) |

### 8.3. Форма кавычек и имена аргументов
Двойные кавычки; `LIMIT(MN := …, IN := …, MX := …)`; `TIME_TO_INT(IN := …)`; `CONCAT(IN1 := …, IN2 := …)`. Время читается входными параметрами `СистемаДеньНеделиТекст`, `СистемаЧас`, `СистемаМин`.
