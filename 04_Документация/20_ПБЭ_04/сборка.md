# ПБЭ № 4. Инструкция по сборке в MasterSCADA 4D 1.3.10.34633

**Кто выполняет:** пользователь («руки»). Материал — этот документ и файлы `параметры.md`, `окна_и_связи.md`, `st/Программа_ST_1.st`.
**Что получится:** библиотечный элемент с 2 окнами и 103 параметрами, компилируемый и проверяемый на тестовых значениях.
**Оценка времени:** ≈ 7,5 ч.

> Все шаги выполняются **в собственном проекте разработки**, без ПЛК (ТЗ п. 1.4, 4). Перед началом — сделать резервную копию (ТЗ п. 3, последний абзац).

## Шаг 0. Подготовка (15 мин)

1. Открыть MasterSCADA 4D 1.3.10.34633.
2. Создать **новый проект разработки** (не рабочий проект ДИГАМ — он не передаётся, ТЗ п. 4).
3. Сделать резервную копию папки проекта (архивом). Дальше копии — перед каждым существенным изменением.
4. Открыть рядом файл `20_ПБЭ_04/параметры.md` — из него берутся имена и типы.

**Проверка шага:** проект открывается, дерево пустое.

   ```

   ├── Программы
   ```

## Шаг 3. Настройка конвертеров (1 ч)

Конвертеры настраиваются **на параметрах типа**, поэтому настраиваются один раз для N = 1, затем копируются вместе с параметром.

### 3.1. `СостояниеN` (INT) — дискретный конвертер

Открыть свойства параметра `Состояние1` → раздел `Конвертация`.

| № строки | Значение | Текст | Цвет заливки | Цвет текста |
|---|---|---|---|---|
| 1 | `0` | Стоп | `rgb(240,240,240)` | `#202020` |
| 2 | `1` | Работа | `rgb(0,176,80)` | `#FFFFFF` |
| 3 | `2` | Предупреждение | `rgb(255,192,0)` | `#202020` |
| 4 | `3` | Авария | `rgb(255,0,0)` | `#FFFFFF` |
| 5 | `4` | Нет данных | `rgb(128,128,128)` | `#FFFFFF` |

> **Внимание.** **Цвета набирать именно как `rgb(0,176,80)`.** Не `#00B050`. Это требование ТЗ п. 3.

### 3.2. `ЕстьАварияN` (BOOL) — булев конвертер
**Строка `False` — ПЕРВАЯ.**

| № | Значение | Текст | Цвет заливки | Цвет текста |
|---|---|---|---|---|
| 1 | **`False`** | Норма | `rgb(240,240,240)` | `#202020` |
| 2 | `True` | Авария | `rgb(255,0,0)` | `#FFFFFF` |

### 3.3. `ДиагНетСвязиN` (BOOL) — булев конвертер
**Строка `False` — ПЕРВАЯ.**

| № | Значение | Текст | Цвет заливки | Цвет текста |
|---|---|---|---|---|
| 1 | **`False`** | Есть связь | `rgb(240,240,240)` | `#202020` |
| 2 | `True` | Нет данных | `rgb(128,128,128)` | `#FFFFFF` |

### 3.4. `ТемператураN` (REAL) — аналоговый конвертер

| № | Условие | Текст | Цвет текста |
|---|---|---|---|
| 1 | `< 0` | Низкая | `rgb(0,112,192)` |
| 2 | `0 … 40` | Норма | `rgb(0,176,80)` |
| 3 | `> 40` | Высокая | `rgb(255,0,0)` |

**Проверка шага:** первые строки булевых конвертеров — `False`; все цвета в форме `rgb(...)`.
**Тесты:** T4-30, T4-31, T4-32.

## Шаг 4. Программа ST (30 мин)

1. Открыть `Ресурсы → Программы`.
2. Создать программу с именем `Программа_ST_1`, язык — **ST**.
3. Открыть файл `20_ПБЭ_04/st/Программа_ST_1.st`, скопировать **всё** содержимое и вставить в редактор.
4. Скомпилировать (кнопка компиляции программы).

**Ожидание:** компиляция без ошибок.

**Если появились ошибки — что проверить (по частоте):**

| Ошибка | Причина | Что делать |
|---|---|---|
| «Неизвестный идентификатор `АвАвария1`» | параметр не создан или назван иначе | сверить имя с `параметры.md`; регистр и кириллица должны совпадать точно |
| «Неизвестный идентификатор `i`» | потерян блок `VAR … END_VAR` | вставить начало файла заново |
| «Ожидается `;`» | обрыв строки при копировании | вставить файл целиком, а не построчно |
| Ошибка на `Состояние1Текст` | параметр назван `СостояниеТекст1` вместо `Состояние1Текст` | переименовать параметр (в артефактах порядок: сначала индекс) |
| Ошибка компиляции на строковых литералах | **форма проверена**: в среде требуются двойные кавычки | в файле использованы двойные кавычки; если ошибка есть — заменить программу из файла |

> **Форма кавычек подтверждена при проверке среды:** в ST требуются **двойные** кавычки. В файле программы они уже двойные — правок не требуется. Если компилятор всё же укажет на литерал, значит строка повреждена при копировании: вставить файл целиком.

**Проверка шага:** программа компилируется.
**Тест:** T4-04.

## Шаг 10. Резервное копирование и сдача (15 мин)

1. Сделать архив проекта разработки.
2. Сформировать папку сдачи:
   ```
   ПБЭ-4/
   ├── <проект разработки>.zip
   ├── <библиотека>.mslb          ← см. примечание ниже
   └── описание_параметров_ПБЭ_4.md   ← это 20_ПБЭ_04/параметры.md
   ```

### Как получить `.mslb` (файл библиотеки)
Файл библиотеки формируется **средой**, а не текстом. Общий порядок:
1. Убедиться, что элемент лежит в разделе `Библиотеки` (не в `Объекты`).
2. Найти в контекстном меню раздела/элемента команду экспорта/сохранения библиотеки (обычно `Экспорт библиотеки`, `Сохранить библиотеку как…`).
3. Указать путь и имя файла `.mslb`.
4. **Точное расположение команды в версии 1.3.10.34633 я утверждать не могу:** библиотека с образцами ПБЭ в комплект не входит (допущение `D-01`), а схема хранения проекта её не содержит. Если команда не находится — сообщить мне, я дам уточнение по факту увиденного меню.

**Проверка шага:** файл библиотеки создан и открывается в чистом проекте.
