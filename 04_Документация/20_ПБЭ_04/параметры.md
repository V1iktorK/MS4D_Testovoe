# ПБЭ № 4. Таблица параметров

Обозначения: **В** — общий для всех пяти установок; **1…5** — индекс установки (1 = В1.1, 2 = В2.1, 3 = В3.1, 4 = В7, 5 = В9).
Направление: **Вх** — приём из канала (ДИГАМ подключает тег); **Вых** — значение, формируемое ПБЭ; **Настр** — настройка экземпляра; **Выч** — вычисляемое внутри ПБЭ.

> В ПБЭ № 4 **нет параметров-команд** (нет направления «запись в оборудование»). Это прямое требование ТЗ: «ПБЭ предназначен только для мониторинга».

---

## 1. Общие параметры

| № | Параметр | Тип | Напр. | Диапазон / значения | Описание | Привязка в окнах |
|---|---|---|---|---|---|---|
| 1 | `Название` | STRING | Настр | — | Название группы, напр. «Группа вытяжных установок В1.1…В9, корпус 3» | 4.1 заголовок |
| 2 | `Обозначение` | STRING | Настр | — | Код группы, напр. «Группа В, корп. 3» | 4.1 заголовок, 4.2 |
| 3 | `Корпус` | INT | Настр | 3 | Номер корпуса | 4.1 заголовок |
| 4 | `ДиагНетСвязи` | BOOL | Выч | FALSE/TRUE | Нет связи хотя бы с одной установкой группы | 4.1 индикатор связи |
| 5 | `КолУстановок` | INT | Настр | 5 | Число установок в группе (для скрытия лишних) | — |
| 6 | `ЕстьАвария` | BOOL | Выч | FALSE/TRUE | Есть авария хотя бы у одной установки | 4.1 индикатор «Авария» |
| 7 | `КолАварий` | INT | Выч | 0…5 | Сколько установок в аварии | 4.1 текст |
| 8 | `КолРаботают` | INT | Выч | 0…5 | Сколько установок работают | 4.1 текст |

## 2. Параметры установок (повторяются для индексов 1…5)

Ниже — шаблон. В проекте создаётся 5 наборов; в имени `N` = 1…5.

### 2.1. Настройка (наименование и привязка)

| № | Параметр | Тип | Напр. | Значения по умолчанию (N = 1…5) | Описание |
|---|---|---|---|---|---|
| 10 | `ОбозначениеN` | STRING | Настр | `В1.1`, `В2.1`, `В3.1`, `В7`, `В9` | Код установки. **Видно при потере связи** |
| 11 | `НазваниеN` | STRING | Настр | «Вытяжная установка В1.1» … | Полное название |
| 12 | `ПомещениеN` | STRING | Настр | — | Номер обслуживаемого помещения |
| 13 | `ПомещениеNНазначение` | STRING | Настр | — | Назначение помещения |
| 14 | `НастрЕстьСигналN` | BOOL | Настр | `TRUE` | Есть сигнал состояния |
| 15 | `НастрЕстьАварияN` | BOOL | Настр | `TRUE` | Есть сигнал аварии |
| 16 | `НастрЕстьТемператураN` | BOOL | Настр | `TRUE` | Есть датчик температуры |
| 17 | `НастрЕстьЗаслонкаN` | BOOL | Настр | `FALSE` | Есть заслонка |

### 2.2. Сигналы от оборудования (приём из канала — подключает ДИГАМ)

| № | Параметр | Тип | Напр. | Диапазон | Описание |
|---|---|---|---|---|---|
| 20 | `РаботаN` | BOOL | Вх | FALSE/TRUE | Дискретный сигнал «установка работает» |
| 21 | `АвАварияN` | BOOL | Вх | FALSE/TRUE | Дискретный сигнал аварии установки |
| 22 | `ТемператураN` | REAL | Вх | −60…150 °C | Температура (при `НастрЕстьТемператураN = TRUE`) |
| 23 | `ЗаслонкаОткрытаN` | BOOL | Вх | FALSE/TRUE | Конечник «заслонка открыта» (при `НастрЕстьЗаслонкаN = TRUE`) |
| 24 | `ЗаслонкаЗакрытаN` | BOOL | Вх | FALSE/TRUE | Конечник «заслонка закрыта» |
| 25 | `КачествоN` | INT | Вх | 0…3 | Признак качества сигнала (`StatusCode`): 0 — хороший, 1 — неопределённый, 2 — плохой, 3 — нет данных |
| 26 | `ДиагНетСвязиN` | BOOL | Вх | FALSE/TRUE | Нет связи с установкой (от канала или вычислено) |

### 2.3. Вычисляемые параметры состояния

| № | Параметр | Тип | Напр. | Диапазон / значения | Описание |
|---|---|---|---|---|---|
| 30 | `СостояниеN` | INT | Выч | 0 Стоп, 1 Работа, 2 Предупреждение, 3 Авария, 4 Нет связи | Состояние установки, вычисляется по приоритету |
| 31 | `СостояниеNТекст` | STRING | Выч | «Стоп»/«Работа»/«Предупреждение»/«Авария»/«Нет данных» | Текст для отображения |

## 3. Полный перечень параметров (сводно)

**Общих:** 8. **На установку:** 4 (настройка наименования) + 4 (признаки состава) + 7 (сигналов) + 4 (вычисляемых) = **19**. **На 5 установок:** 95. **Итого параметров ПБЭ № 4: 103.**

> Если ДИГАМ передаст фактический состав сигналов (`D-40`), правке подлежит только §2.2 — добавление или удаление строк. Структура §2.3 и §2.4 не меняется.

## 4. Конвертеры параметров

### 4.1. `СостояниеN` (INT) — дискретный конвертер
Строки по возрастанию кода; цвета — `rgb(...)`:

| № | Значение | Текст | Цвет заливки | Цвет текста |
|---|---|---|---|---|
| 1 | `0` | Стоп | `rgb(240,240,240)` | `#202020` |
| 2 | `1` | Работа | `rgb(0,176,80)` | `#FFFFFF` |
| 3 | `2` | Предупреждение | `rgb(255,192,0)` | `#202020` |
| 4 | `3` | Авария | `rgb(255,0,0)` | `#FFFFFF` |
| 5 | `4` | Нет данных | `rgb(128,128,128)` | `#FFFFFF` |

### 4.2. `ЕстьАварияN` (BOOL) — булев конвертер
Порядок строк: **`False` первой**.

| № | Значение | Текст | Цвет заливки | Цвет текста |
|---|---|---|---|---|
| 1 | **`False`** | Норма | `rgb(240,240,240)` | `#202020` |
| 2 | `True` | Авария | `rgb(255,0,0)` | `#FFFFFF` |

### 4.3. `ДиагНетСвязиN` (BOOL) — булев конвертер
Порядок строк: **`False` первой**.

| № | Значение | Текст | Цвет заливки | Цвет текста |
|---|---|---|---|---|
| 1 | **`False`** | Есть связь | `rgb(240,240,240)` | `#202020` |
| 2 | `True` | Нет данных | `rgb(128,128,128)` | `#FFFFFF` |

### 4.4. `ТемператураN` (REAL) — аналоговый конвертер (норма/выход за пределы)

| № | Условие | Текст | Цвет текста |
|---|---|---|---|
| 1 | `< 0` | Низкая | `rgb(0,112,192)` |
| 2 | `0 … 40` | Норма | `rgb(0,176,80)` |
| 3 | `> 40` | Высокая | `rgb(255,0,0)` |

> Пороговые значения — настройки (`ТемператураНизкая`, `ТемператураВысокая`), но для ПБЭ № 4 пороги зашиты как ориентир: реальные уставки не предусмотрены (уставок в ПБЭ № 4 нет). При необходимости пороги выносятся в параметры, но это уже «настройка», а не «уставка», и допустимо.

### 4.5. Формат отображения
| Параметр | Формат |
|---|---|
| `ТемператураN` | `{f1} °C` |
| `ОбозначениеN` | без формата |
| `СостояниеNТекст` | без формата (текст из конвертера) |

Все поля ввода/вывода — **только вывод**. Редактируемых полей в ПБЭ № 4 нет.

## 5. Сводка соответствия требованиям типов

| Код | Требование | Как выполнено |
|---|---|---|
| T-2 | Отдельные BOOL-аварии ⇒ маски и разбора **нет** | Аварии — `АвАварияN` (BOOL). Параметров-масок DINT в ПБЭ № 4 **нет** |
| T-3 | Цвета конвертеров `rgb(...)` | §4.1–4.4 |
| T-4 | `False` первой строкой | §4.2, §4.3 — первая строка `False` |
| T-5 | Цвет текста `#RRGGBB` | §4.1–4.4, колонка «Цвет текста» |
| T-6 | Код аварии `-1` при отсутствии | **Не применимо**: код аварии в ПБЭ № 4 не формируется (нет разбора и нет журнала) |
| T-7 | Пишущий элемент читает | **Не применимо**: пишущих элементов нет |
| T-8 | Команды действиями по событию | **Не применимо**: команд нет |
| T-9 | Обозначение и помещения видны при потере связи | `ОбозначениеN`, `ПомещениеN`, `ПомещениеNНазначение` — выведены без зависимости от связи |
| T-10 | Отключённая функция не формирует команду | **Не применимо**: команд нет. Скрытие графики по `Настр…` выполняется |
| T-12 | `LIMIT` для ограничения вводимых уставок | **Не применимо**: ввода нет |
