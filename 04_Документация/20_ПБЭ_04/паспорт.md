# ПБЭ № 4. Паспорт

## 1. Идентификация

| Параметр | Значение |
|---|---|
| **Номер ПБЭ по Перечню** | 4 |
| **Наименование по Перечню** | Универсальный ПБЭ группы вытяжных установок без ПЛК, корпус 3 |
| **Граница экземпляра** | Один экземпляр — **вся группа из пяти установок**: В1.1, В2.1, В3.1, В7, В9 |
| **Количество экземпляров в проекте** | **1** |
| **Количество окон** | **2** (позиции 4.1, 4.2) |
| **Система применения** | Корпус № 3, вытяжные установки без ПЛК |
| **Роль** | Только мониторинг |
| **Приоритет разработки** | 1-й (первый в очереди) |

## 2. Назначение

ПБЭ отображает состояние группы из пяти вытяжных установок корпуса № 3, не имеющих собственных ПЛК. Управление отсутствует: сигналы приходят от существующих шкафов и датчиков, ПБЭ их только показывает.

## 3. Состав окон (дословно по Перечню ПБЭ)

| № окна | Наименование окна | Тип окна | Назначение |
|---|---|---|---|
| **4.1** | Мнемосхема установки | `MasterSCADA.View.Screen` | Общая мнемосхема группы с независимой индикацией каждой из пяти установок |
| **4.2** | Точки установок на плане | `MasterSCADA.View.Screen` | Отдельные точки пяти установок группы на плане этажа |

## 4. Что предусмотрено ТЗ

Из ТЗ, приложение 1, часть 2 (ПБЭ № 4):

> «ПБЭ № 4 — универсальный библиотечный элемент группы вытяжных установок без ПЛК корпуса 3. Один экземпляр охватывает всю группу: В1.1, В2.1, В3.1, В7 и В9. Предусматривается один экземпляр.
> Разрабатываются два окна по позициям 4.1–4.2: общая мнемосхема группы и представление отдельных точек установок на плане. Для каждой установки предусмотрены собственные обозначение, параметры и независимая индикация состояния по дискретным сигналам. Состав сигналов передаёт ДИГАМ.
> ПБЭ предназначен только для мониторинга. Органы управления, всплывающие окна, уставки, расписание, тренды и архивирование не предусматриваются.»

Из ТЗ, приложение 2:

> «Для ПБЭ № 4 разрабатываются два окна: 4.1 «Мнемосхема установки» — общая мнемосхема группы с независимой индикацией каждой установки; 4.2 «Точки установок на плане» — отдельные точки установок группы. Органы управления и всплывающие окна отсутствуют.»

## 5. Что ПБЭ № 4 НЕ содержит (и это требование, а не упущение)

| Не содержится | Пункт ТЗ |
|---|---|
| Органы управления (СТАРТ, СТОП, СБРОС, РАСПИСАНИЕ) | прил. 1 ч. 2 |
| Всплывающие окна и кнопки перехода | прил. 1 ч. 2; прил. 2 |
| Уставки и любые поля ввода | прил. 1 ч. 2 |
| Планировщик и окно «Планировщик» | прил. 1 ч. 2; п. 3.1 |
| Тренды (окна «Температуры», «Общая диаграмма», «Производительность вентиляторов», «Дискретные значения») | прил. 1 ч. 2; Перечень (у № 4 таких позиций нет) |
| Архивирование | прил. 1 ч. 2 |

## 6. Варианты исполнения

ПБЭ № 4 применяется к единственной группе, поэтому **выбор варианта оборудования не предусмотрен**. Настройками экземпляра задаются только:

| Настройка | Тип | Назначение |
|---|---|---|
| `Название` | STRING | название группы (отображается в заголовке) |
| `Корпус` | INT | номер корпуса (3) |
| `Обозначение1…5` | STRING | коды установок: В1.1, В2.1, В3.1, В7, В9 |
| `Название1…5` | STRING | полные названия установок |
| `Помещение1…5` | STRING | обслуживаемое помещение |
| `Помещение1Назначение…` | STRING | назначение помещения |
| `НастрЕстьТемпература1…5` | BOOL | есть ли датчик температуры у установки |
| `НастрЕстьАвария1…5` | BOOL | есть ли сигнал аварии |
| `НастрЕстьЗаслонка1…5` | BOOL | есть ли заслонка |

При `Настр… = FALSE` соответствующая графика скрывается и поле не отображается (ТЗ п. 1.3, 3.1).
