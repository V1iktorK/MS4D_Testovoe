### T4-05. Подача разных состояний на пять установок

| Установка | `РаботаN` | `АвАварияN` | `ДиагНетСвязиN` | `ТемператураN` |
|---|---|---|---|---|
| 1 — В1.1 | TRUE | FALSE | FALSE | 24,5 |
| 2 — В2.1 | TRUE | TRUE | FALSE | 26,1 |

| 2 — В2.1 | 3 | Авария | TRUE |
| 3 — В3.1 | 0 | Стоп | FALSE |
| 4 — В7 | 4 | Нет данных | FALSE |
| 5 — В9 | 1 | Работа | FALSE |

### T4-06. Независимость — изменение одной не трогает остальные
**Шаги.** Имея состояние из T4-05, переключить `АвАвария2` с TRUE на FALSE, затем обратно.
**Ожидание.** Меняется **только** блок В2.1. Показания `В1.1`, `В3.1`, `В7`, `В9` **не меняются** ни на мгновение.
**Основание:** ТЗ прил. 1 ч. 2 — «независимая индикация состояния».
**Итог:** ______

### T4-07. Приоритет состояния
**Шаги.** Для установки 1 последовательно:
1. `АвАвария1 = TRUE`, `ДиагНетСвязи1 = TRUE`;
2. `АвАвария1 = FALSE` (связь всё ещё нет);
3. `ДиагНетСвязи1 = FALSE` (работа TRUE);
4. `Работа1 = FALSE`.

**Ожидание.** `Состояние1` поочерёдно: **3** (Авария) → **4** (Нет данных) → **1** (Работа) → **0** (Стоп).
**Итог:** ______

### T4-08. Авария при потере связи не считается аварией

**Ожидание.** `Состояние1 = 4` («Нет данных»), `ЕстьАвария1 = FALSE`. Установка в списке аварий группы **не появляется**, `КолАварий` её не считает.
