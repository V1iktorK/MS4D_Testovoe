## 4. Соответствие файлов требованиям ТЗ

ТЗ п. 1.4 перечисляет состав работы. Сопоставление:

| Требование ТЗ п. 1.4 | Артефакт |
|---|---|
| «создание или адаптация окон, указанных в Перечне ПБЭ» | `окна_и_связи.md` каждого ПБЭ + `сборка.md` |
| «создание параметров для отображения состояния, управления, настройки и выбора варианта исполнения» | `параметры.md` каждого ПБЭ |
| «настройку внутренних связей между параметрами, графическими объектами и программами ПБЭ» | `окна_и_связи.md` — карты связей |
| «реализацию предусмотренной для данного ПБЭ обработки данных и формирования команд, включая расшифровку аварий, преобразование значений и формирование значений для записи» | `st/Программа_ST_1.st` каждого ПБЭ |
| «настройку предусмотренных для данного ПБЭ сообщений, трендов и архивирования» | `параметры.md` §сообщения/тренды/архивирование + `окна_и_связи.md` |
| «Исполнитель проверяет работу разработанных ПБЭ в отдельном проекте разработки» | `тесты.md` каждого ПБЭ — **492 теста** |

ТЗ раздел 5 перечисляет проверяемое ДИГАМ:

| Что проверяет ДИГАМ | Артефакт |
|---|---|
| «комплектность переданных материалов» | Этот документ + `96_Инструкция_приёмки.md` §3 |
| «соответствие состава ПБЭ, окон и вариантов исполнения ТЗ и Перечню ПБЭ» | `01_Реестр_окон_ПБЭ.md` + `паспорт.md` каждого ПБЭ (чек-лист) |
| «соответствие оформления и структуры согласованным образцам» | `12_Каркас_общих_окон.md` + эскизы в `окна_и_связи.md` |
| «работу параметров, внутренних связей, индикации, команд и предусмотренных функций на тестовых значениях» | `тесты.md` каждого ПБЭ |
| «подключение библиотеки, создание и настройку экземпляров в версии MasterSCADA 4D, указанной в ТЗ» | `сборка.md` каждого ПБЭ, шаги создания экземпляров |
