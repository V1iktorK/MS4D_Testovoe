# ПБЭ № 5. Инструкция по сборке в MasterSCADA 4D 1.3.10.34633

**Кто выполняет:** пользователь. Материал — этот документ плюс `параметры.md`, `окна_и_связи.md`, `st/Программа_ST_1.st`.
**Что получится:** библиотечный элемент системы кондиционирования VRF с 9 окнами, групповым экземпляром на корпус и механизмом выбранного блока.
**Оценка времени:** ≈ 33 ч.

> **ПБЭ № 5 не похож на остальные семь.** Все прочие ПБЭ — «один экземпляр = одна установка». Здесь **один экземпляр = вся система корпуса**, внутри которой до **66 блоков**, каждый со своими параметрами. Поэтому объём параметров и связей **втрое больше**, чем у любого другого ПБЭ.

## Шаг 2. Параметры (10 ч — самый объёмный шаг во всём комплекте)

### 2.1. Порядок создания

| № | Группа | Кол-во | §  `параметры.md` |
|---|---|---|---|
| 1 | Общие | 14 | §1 |
| 2 | Состояния системы | 12 | §2 |
| 3 | Выбранный блок | 15 | §3 и §3.1 |
| 4 | **Наружные блоки** | **70** (7 × 10) | §4 |
| 5 | **Внутренние блоки** | **792** (66 × 12) | §5 |

### 2.2. Создание блока наружного блока

**Способ:** создать 10 параметров для `Нар01`, затем **скопировать 6 раз**, заменив `01` на `02`…`07`.

Имена (для индекса `NN`):
```
Нар<NN>Обозначение      STRING  Настр
Нар<NN>Зона             STRING  Настр
Нар<NN>Включение        BOOL    Вх+Вых
Нар<NN>Компрессор       BOOL    Вх
Нар<NN>Режим            INT     Вх+Вых
Нар<NN>Ошибка           BOOL    Вх
Нар<NN>Защита           BOOL    Вх
Нар<NN>ОшибкаКанала     BOOL    Вх
Нар<NN>КодОшибки        INT     Вх
Нар<NN>ТекстОшибки      STRING  Выч
```
> Имя `Нар01Применен` **не создавать** — это вычисляемый параметр, см. §2.4.

### 2.3. Создание блока внутреннего блока

**Способ:** создать 12 параметров для `Вн01`, затем **скопировать 65 раз**, заменив `01` на `02`…`66`.

Имена (для индекса `NN`):
```
Вн<NN>Обозначение      STRING  Настр
Вн<NN>Помещение        STRING  Настр
Вн<NN>Применен         BOOL    Выч
Вн<NN>Включение        BOOL    Вх+Вых
Вн<NN>Уставка          REAL    Вх+Вых   16…30, шаг 0,5
Вн<NN>ТПомещения       REAL    Вх         -60…150
Вн<NN>Режим            INT     Вх+Вых    0…4
Вн<NN>Вентилятор       INT     Вх+Вых    0…3
Вн<NN>Ошибка           BOOL    Вх
Вн<NN>Защита           BOOL    Вх
Вн<NN>РежимКанал       INT     Вых
Вн<NN>ВентиляторКанал  INT     Вых
```

> **Внимание.** **Только эти 12.** Не добавлять других параметров блока: ТЗ даёт **закрытый перечень** из 7 параметров (включение, уставка, T помещения, режим, скорость, ошибка, защита). Остальные 5 — реквизиты и формирование для записи.

> **Внимание.** **Используйте ДВУЗНАЧНЫЕ индексы** (`01`…`66`). Иначе в редакторе `Вн9` окажется **после** `Вн10`, и работать с 66 блоками будет мучительно.

### 2.4. Проверка после создания

| Что | Ожидание |
|---|---|
| Наружных параметров | 7 × 10 = **70** |
| Внутренних параметров | 66 × 12 = **792** |
| Общих, состояний, выбранного | 14 + 12 + 20 = **46** |
| **Итого** | **≈ 903** |

**Проверка:** открыть окно, убедиться в быстродействии. **Тесты:** T5-08, T5-09, T5-10, T5-11.

## Шаг 3. Конвертеры (3 ч)

По `параметры.md` §7. **Ключевая экономия:** конвертеры настраиваются **на параметре типа**, поэтому настраиваются **один раз** для `Вн01`, а затем копируются вместе с параметром.

Порядок:
1. `СостояниеСистемы` — дискретный, 5 строк.
2. **`Вн01Режим`** — дискретный, 5 строк (Авто / Охлаждение / Нагрев / Вентиляция / Осушение) — §7.2.
3. **`Вн01Вентилятор`** — дискретный, 4 строки (Авто / Низкая / Средняя / Высокая) — §7.3.
4. `Вн01Включение`, `Вн01Ошибка`, `Вн01Защита`, `Вн01Применен` — булевы, `False` **первой** строкой — §7.4.
5. `Нар01*` — аналогично.
6. `Вн01Уставка`, `Вн01ТПомещения` — аналоговые — §7.5.

> **Внимание.** Цвета — `rgb(...)`. `False` — первой строкой в **каждом** булевом конвертере. Тесты **T5-44**, **T5-45**.

**При копировании параметров конвертеры копируются автоматически** — их не нужно настраивать 66 раз.

## Шаг 4. Программа ST (6 ч)

1. `Ресурсы → Программы` → `Программа_ST_1`, язык ST.
2. Скопировать **весь** текст из `st/Программа_ST_1.st` (2018 строк, 7 разделов; разделы 4, 5, 6 — по 66 индексов).
3. Скомпилировать.

### 4.1. Что проверить в коде

| Раздел | Содержание |
|---|---|
| 1 | Ограничение настроек и уставок **всех** блоков 16…30 |
| 2 | Применимость блоков (`Вн<NN>Применен`, `Нар<NN>Применен`) |
| 3 | Формирование значений для записи (`*Канал`) |
| **4** | **Копирование выбранного блока** |
| **5** | **Обратная запись команд выбранного блока** |
| 6 | Агрегация по системе |
| 7 | Аварии и состояние |

**Чего быть не должно:** `GetBit`, DINT-параметры-маски, планировщик, кнопка «РАСПИСАНИЕ», ротация вентиляторов.

### 4.2. Охват индексов

**Программа реализует копирование выбранного блока, обратную запись команд и сводную агрегацию для всех 66 индексов** (разделы 4, 5 и 6 программы — по 66 ветвей). См. `параметры.md` §12.

**Что это значит практически:**
* программа **компилируется и работает** на любом числе блоков от 1 до 66;
* страница блоков (`СтраницаБлоков`, окна 5.4 и 5.7) — только отображение, на логику не влияет;
* доработок по охвату индексов не требуется.

**Что делать:**
1. Собрать по этой инструкции, проверить тесты на 1, 11 и 66 блоках (границы страниц).

**Тест:** T5-50.

### 4.3. Возможные ошибки компиляции

| Ошибка | Причина | Решение |
|---|---|---|
| «Неизвестный идентификатор `Вн66Применен`» | не созданы параметры | шаг 2.3 |
| «Неизвестный идентификатор `СтраницаБлоков`» | параметр не создан | `параметры.md` §3, № 56 |
| «Тип несовместим» на сравнении `Инд` | иной тип | проверить, что `ВыбранныйБлок` — INT |
| Ошибка на строковых литералах | нужны двойные кавычки | заменить все и сообщить |

## Шаг 5. Окна 5.1–5.4, 5.6, 5.7 — таблицы (6 ч)

### 5.1. Порядок работы

1. Создать окна с именами **дословно** по Перечню.
2. Создать **шапки** (5.1, 5.3, 5.6) — по 8 подписей, без связей.
3. Создать **одну строку** каждого типа:
   * 5.2 — строка наружного блока (`Нар01`), 8 полей;
   * 5.4 — строка внутреннего блока (`Вн01`), 8 полей;
   * 5.7 — строка уставок (`Вн01`), 8 полей, из них **4 пишущих с обеими связями**.
4. **Проверить** работу на блоке 01.
5. **Размножить**: 5.2 — 6 раз (итого 7), 5.4 и 5.7 — 65 раз (итого 66).
6. В каждой копии заменить **все** вхождения `01` на нужный индекс — **в именах объектов и в связях**.

### 5.2. Отображение номеров строк

Для удобства вывести в каждой строке её индекс (`Вн<NN>Применен` не поможет — он булев). Использовать текст с номером или порядковый номер объекта в имени.

### 5.3. (?) Главный риск — «съезжание» индексов

При 66 копированиях вероятность ошибки высока. **Меры:**
1. Размножать **блоками по 10** и после каждого блока проверять выборочно 2–3 строки.
2. Заполнить блоки 25, 26, 27 **разными** значениями и проверить, что каждое попало по адресу. **Тест T5-17**.
3. Вести таблицу соответствия «имя объекта → индекс» в отдельном файле.

### 5.4. Скрытие строк
Для каждой строки: входящая связь на свойство **«Видимость»** ← `Вн<NN>Применен` (или `Нар<NN>Применен`).

> **Внимание.** **Связок «Видимость» в окнах 5.2 + 5.4 + 5.7 = 7 + 66 + 66 = 139.** Это отдельная работа, не забудьте про неё в оценке времени.

**Проверка шага:** T5-18, T5-19, T5-20, T5-22, T5-23, T5-27.

## Шаг 6. Окно 5.5 «Метка блока» (2 ч)

### 6.1. Создать одну метку
**Три объекта** (дословно по ТЗ прил. 2 п. 2.2):
1. `Метка_ИмяБлока` ← `ВыбранныйБлокОбозначение` (Текст);
2. `Метка_ИндикаторВключения` ← `ВыбранныйБлокВключение` (**Заливка**, конвертер);
3. `Метка_Температура` ← `ВыбранныйБлокТПомещения` (Текст, `{f1} °C`).

### 6.2. Настроить событие клика (ключевое)
**Событие:** `MarkerClickEvent`
**Действие:** `Задать параметр` → `ВыбранныйБлок := <номер метки>`

> **Внимание.** **Это и есть реализация требования ТЗ «команды относятся к выбранному блоку».** Без этой настройки механизм не работает. **Тест T5-15.**

### 6.3. Размножить метку
Скопировать метку 65 раз; в копии с номером `K` задать `ВыбранныйБлок := K`. Расставить по плану этажа.

> **Примечание.** Все 66 меток отображают **выбранный** блок (допущение `D-93`) — это сделано, чтобы не дублировать графику. Если требуется, чтобы каждая метка показывала **свой** блок, заменить связи на `Вн<NN>…` напрямую.

**Проверка шага:** T5-15, T5-21.
