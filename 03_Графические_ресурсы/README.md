**Куда подставляется:** в свойства окна ПБЭ как фоновое изображение (ресурс изображения элемента, тип `MasterSCADA.View.Resource.Image`). Соответствие окон и файлов — в таблице выше.

**Что заменить при получении от ДИГАМ:**
* мнемосхемы приточных установок — на чертежи установок (ПБЭ № 1, 7);
* мнемосхемы вытяжных — ПБЭ № 2, 3, 6, 8;
* VRF — схему холодильного контура корпуса (ПБЭ № 5);
* планы этажей — поэтажные планы корпусов 3, 8, 22 (окна «Точки установок на плане»).

**Проверка:** файлы сверены с реестром — наличие, размеры, соответствие именам окон.
