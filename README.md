# УПКБ-6 — библиотека ПБЭ для MasterSCADA 4D

Комплект по ТЗ от 14.10.2026 на разработку пользовательских библиотечных элементов (ПБЭ) для проекта
УПКБ-6 (АО «УПКБ «Деталь», корпуса № 3, 8, 22). Заказчик разработки — ООО «ДИГАМ».

Среда: **MasterSCADA 4D 1.3.10.37086** (в ТЗ указана 1.3.10.34633 — расхождения, подтверждённые
и неподтверждённые подписи сведены в `04_Документация/010_Сверка_со_средой_1.3.10.37086.md`).

## Что в комплекте

| Папка | Содержимое |
|---|---|
| `01_Библиотека/` | `library_UPKB-6.ms4proj` — библиотечный проект MasterSCADA 4D: 8 элементов, 87 окон, 2 368 параметров, 8 ST-программ |
| `02_Проект_разработки/` | `project_UPKB-6` — проект с 55 экземплярами (52 по Перечню + 3 тестовых для проверки вариантов ПБЭ № 1) |
| `03_Графические_ресурсы/` | 6 подложек мнемосхем (заглушки, см. оговорки) и реестр файлов |
| `04_Документация/` | паспорта, таблицы параметров, карты связей с окнами, тексты ST-программ, тестовые сценарии, инструкции по сборке, реестры и отчёты |

## Как открыть

1. Запустить MasterSCADA 4D 1.3.10 (проверено на сборке 37086).
2. `Файл → Открыть проект` → папка `01_Библиотека/library_UPKB-6.ms4proj` (внутри `info.xml` и
   `library_UPKB-6.fdb`). Элементы появятся в разделе **Библиотеки → УПКБ-6**.
3. Так же открыть `02_Проект_разработки/project_UPKB-6`. Экземпляры — в разделе **Объекты**.

Библиотека подключается к проекту по GUID, пути к файлу в базе проекта нет (допущение `D-104`):
если среда не нашла библиотеку, положить её в каталог библиотек среды.

## Что осталось сделать в среде

1. **Шаг 0 — предел числа параметров.** ПБЭ № 5 объявляет 903 параметра; поведение типа на таком
   объёме нужно подтвердить до основной сборки (`25_ПБЭ_05/сборка.md`, §0.1).
2. Открыть библиотеку и проект, убедиться в составе (8 элементов, 87 окон, 55 экземпляров).
3. Прогнать тесты по файлам `тесты.md`.
4. Экспортировать библиотеку в `.mslb` для передачи ДИГАМ.

* **Подложки мнемосхем** — заглушки нужного размера: оригиналы ДИГАМ не передавал (допущение `D-03`).

  ПБЭ и Перечню ПБЭ. Все спорные места вынесены в `04_Документация/99_Допущения.md` — 56 действующих
  допущений, у каждого указана причина и способ замены на фактические данные.

* ПБЭ № 4 — только контроль и индикация, без органов управления (требование ТЗ).
